Browser extension

The Brique extension connects your browser to your instances. A page of an associated instance is admitted as local.ui; for instances that are not local, the identity instance signs on your behalf. Each browser has its own extension, and each can have its own instances.

How to install it in a browser
  1. Tick the instances to associate with the browser, pick the one that carries the identity, then "Associate": the launcher prepares the extension and registers what is needed.
  2. Click "Open the extensions page", turn on developer mode, then "Load unpacked" and choose the folder shown.
  3. Then open the page of an instance with its button: the page connects by itself, without a click.
